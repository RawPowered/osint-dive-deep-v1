# Phase 2 Admin UIX

The existing DiveDeep admin is the sole operational surface.

## Operations-first navigation

- Overview: current service condition and queue totals
- Customers: customer records and workflow status
- Work Queue: intake, ready, capacity, running, review, and blocked lanes
- Recon Jobs: execution progress and actions
- Worker Pools: Cloud Run configuration, capacity, and versioning
- Source Catalog: Phase 1 resources, pools, source sets, and package coverage
- Findings: confirmed and review findings
- Evidence Review: blurred candidate wall and reviewer disposition
- Removal Cases: request workflow
- Monitoring: response and reappearance operations
- Retention: expiring and overdue records

## Recovery tools

Manual packet export and import remain available, but are visually demoted so they are not mistaken for the intended automated workflow.
