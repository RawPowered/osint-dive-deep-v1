Secure owner bootstrap

DiveDeep will generate an obfuscated root-owner username and a strong password from an ephemeral 256-bit seed. The seed is erased immediately and is never stored or returned.

The owner credentials and private launch URL are revealed once. Have a password manager ready before installing.

Customer website connection

Install the Node/API package first. Use the public customer-site URL and this API URL. For cookie security, use sibling HTTPS subdomains such as https://demo.example.com and https://api.demo.example.com.
