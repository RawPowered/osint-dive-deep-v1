# OSINT Dive Deep v1 — Research Studio

The investigation application includes People & Identity, Property Intelligence, Geo Explorer, Tax & Permits, Domain Security, Discovery, Web Validation, Tool Arsenal, case evidence, image research and privacy workflows.

Use the root [launcher and setup guide](../docs/SETUP.md). Shodan, Sherlock, and Maigret adapters are included; the actual tools and account credentials are optional external dependencies.

Templates start empty. The reusable template contract remains `osint-query-studio-template-v2`. Private cases and generated evidence live outside this source tree. This engine retains compatibility version 5.29.0; the product release is OSINT Dive Deep v1.0.0.
