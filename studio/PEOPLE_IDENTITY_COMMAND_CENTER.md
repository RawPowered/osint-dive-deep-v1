# People & Identity Command Center

The People & Identity Command Center provides one case-scoped path from known identity facts to reviewed, exact-source evidence.

## Workflow

1. **Scope** — add the primary name and known aliases, emails, usernames, phones, locations and profile URLs.
2. **Discover** — select scoped people and prepare the existing People & Identity query matrix, then open Discovery, Web Validation or the Tool Arsenal.
3. **Resolve** — record one reviewed identity link with its exact public URL, matching basis, confidence and analyst notes.
4. **Evidence** — inspect promoted evidence, full discovery observations and findings.
5. **Report** — export one complete JSON report or a normalized identifier CSV.

Discovery candidates do not become resolved identity evidence automatically. Resolution requires an analyst-reviewed source URL and explicit matching basis. Exact local values remain available in the evidence and report exports.

People cases created in the Case Workspace open directly in this command center. Its default stage follows case progress, and its Discovery handoff reuses the existing query matrix and collection pipeline.
