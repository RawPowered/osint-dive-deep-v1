# Case Workspace

The Case Workspace is DiveDeep's starting point. It provides a single case list for research, market, technical, property and privacy-removal work.

DiveDeep now maintains one active-case context. Moving between Research, Property Explorer, Tax & Permits and Privacy carries the compatible case forward instead of silently selecting unrelated work.

## Use

1. Open **Cases** in the sidebar.
2. Search or filter the compact case list, then select a working case.
3. Choose **Resume** to return to the correct DiveDeep workspace.
4. Use **Manage case** to rename, update the objective, complete, archive or restore the case.
5. Review the case's hunts, evidence or activity without leaving the workspace.

The selected case shows a single recommended next action. Continuing routes directly to the appropriate research view, privacy stage or Geo Explorer stage.

For a one-target investigation, open **Quick Recon**, save the target into the active case, and route it directly to the appropriate command center. Selecting **New scratch case** creates the minimum case shell automatically; it remains available in the normal Case Workspace afterward.

New cases require only a hunt type, name and objective. Specialized scope and authorization fields remain inside the relevant hunt so the case form stays small.

Privacy-removal cases are linked to the shared case index after their authorization intake is completed. Existing unlinked privacy cases are linked automatically when opened.

## UI conventions

- A compact case header returns to the Case Workspace from active tools.
- Major workflows render one selected stage at a time.
- Geo Explorer uses Inspect, Fence, Queue and Review stages.
- Property Intelligence uses Scope, Explore, Collect, Enrich, Review, Export and Settings.
- Market, Arsenal, Evidence and Privacy use the same stage-selection pattern.
- Existing stores, collectors, evidence records and exports remain authoritative.
